# Security Policy

## Supported versions

Spectral Relief is currently an early public alpha. Security fixes are applied
to the latest revision on the default branch; older builds are not supported.

## Reporting a vulnerability

Please do not disclose exploitable details in a public issue. Use GitHub's
private vulnerability reporting feature for this repository. If private
reporting is unavailable, open a public issue containing no sensitive details
and ask the maintainer, Nijat Burjiyev, for a private contact channel.

Include the affected commit or version, macOS and host versions, reproduction
steps, expected impact, and whether the issue is reachable while processing
untrusted audio or plug-in state.
